## Acquired Dataset: UCI AI4I 2020 Predictive Maintenance
- **Source**: [UCI Machine Learning Repository (Dataset 601)](https://archive.ics.uci.edu/dataset/601/ai4i%2B2020%2B)
- **Archive URL**: `https://archive.ics.uci.edu/static/public/601/ai4i+2020+predictive+maintenance+dataset.zip`
- **Local Filename**: `data/raw/ai4i2020.csv` *(Git-ignored)*
- **Format**: Comma-Separated Values (CSV) with UTF-8 BOM encoding (`utf-8-sig`)
- **File Size**: 522,048 bytes
- **SHA-256 Hash**: `dc6630cd9b1f0f853922fad78a1b6436570d3f1ec863f1dd5c4340ac56bc8a8e`
- **Scope**: 10,000 observations, 14 columns, 0 null values, 0 duplicate rows.
- **Target Distribution**: `Machine failure == 1`: 339 instances (3.39% failure rate).
- **Synthetic Data Notice**: Generated by Stephan Matzka (HTW Berlin) using physical random walk and operational simulation models to reflect industrial CNC milling machines.

## How to Obtain or Place the Dataset Manually
If setting up a fresh environment without the downloaded file:
1. Download the official archive from:
   `https://archive.ics.uci.edu/static/public/601/ai4i+2020+predictive+maintenance+dataset.zip`
2. Extract `ai4i2020.csv` directly into `data/raw/ai4i2020.csv`.
3. Verify file integrity and generate the validation report:
   ```bash
   python main.py --mode validate
   ```

---

## Data Governance & Version Control Rules
1. **Never commit raw or processed datasets to Git**: Raw and processed CSV/Parquet files are strictly excluded via `.gitignore` to maintain a lightweight repository.
2. **Immutability of Raw Data**: The file `data/raw/ai4i2020.csv` is strictly read-only. Ingestion scripts load this file without in-place modification.
3. **Reproducibility**: Validation and profiling can be executed at any time:
   ```bash
   python main.py --mode validate --output outputs/metrics/data_validation_report.json
   ```
4. **Current Status**: Dataset acquisition, schema validation, and data quality profiling are complete. Preprocessing and model training have not yet occurred.
