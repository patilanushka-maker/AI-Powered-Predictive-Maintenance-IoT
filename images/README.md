# Project Visual Assets Directory

This directory stores visual assets, architecture diagrams, and application screenshots for the repository documentation.

## Directory Structure

```
images/
|-- architecture/
|   `-- system_pipeline.png            # High-level data flow and system architecture
|-- charts/
|   `-- baseline_model_comparison.png  # Model evaluation benchmark curves (ROC, PR)
`-- dashboard/
    |-- fleet_monitoring_overview.png  # Fleet overview and KPI deck screenshot
    |-- telemetry_visualizations.png   # Interactive time-series charts screenshot
    `-- alert_console.png              # Maintenance alert triage console screenshot
```

## Adding Screenshots

1. Capture a screenshot of the running Streamlit dashboard (`http://localhost:8501`).
2. Save image files into the designated folders with the names listed above (or update the corresponding links in `README.md`).
3. Formats supported: PNG, JPG, WebP.
